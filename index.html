如何新增／修改監控平台

GitHub Pages 是靜態網站，清單存在倉庫的 config/banks.js。

  1. 按「⚙️ 管理監控平台」，依教學建立 GitHub PAT（Fine-grained：Contents + Actions 讀寫）。Token 只存瀏覽器 LocalStorage。
  2. 新增、編輯或刪除銀行名稱與官方總覽 URL。
  3. 按「儲存並更新至 GitHub」，前端會用 Contents API 直接 commit config/banks.js。
  4. 再按「🚀 立即執行一次爬蟲」觸發 Repository Dispatch。
  5. 滙豐會跟進 Red Hot Offers 子頁（例如最新優惠）。Mox／AlipayHK 多數詳情只在 App，網站只能抽到公開頁。
  6. 香港 AI：到 OpenRouter Keys 開 key，Secret 名稱必須係 OPENROUTER_API_KEY。

⚙️ 管理監控平台

PAT 只送到 api.github.com，用來寫入 config/banks.js、觸發／取消 Actions。唔會寫進 GitHub 倉庫。

怎樣建立 GitHub PAT？要開咩權限？
  1. 登入 GitHub，撳右上角頭像 → Settings。
  2. 最左邊滾落最底，撳 Developer settings。
  3. 撳 Personal access tokens → Fine-grained tokens → Generate new token。
    直接連結：建立 Fine-grained token
  4. Token name 隨意，例如 hk-promo-dashboard；Expiration 建議 90 日。
  5. Resource owner 選你自己嘅帳號（或這個 repo 所屬 org）。
  6. Repository access 選 Only select repositories，只勾 credit-card-promotion-bot。
  7. 展開 Repository permissions，只開以下兩項（其他保持 No access）：
    • Contents → Read and write（讀寫 config/banks.js）
    • Actions → Read and write（睇狀態、啟動、終止爬蟲）
    Metadata 會自動變成 Read-only，唔使改。
  8. 撳 Generate token，複製 github_pat_…。呢串只會顯示一次，貼入下面欄位。
  9. 如果你比較熟 Classic token：用 Classic token 頁，只勾 repo 即可（權限較闊，較唔建議）。
